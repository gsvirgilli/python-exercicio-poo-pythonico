# Loja Virtual Pythonica

Exercício de Programação Orientada a Objetos em Python: sistema de gerenciamento de estoque para uma loja virtual, com classes para `Produto`, `Estoque` e `Livro` representando o controle de itens e suas regras de negócio.

## Tecnologias

- Python (POO)
- pytest

## Como rodar os testes

```bash
pip install -r dev-requirements.txt
pytest
```
